# Threadlight

Threadlight is a local-first conversation catch-up micro app. It turns pasted chat transcripts into a short summary, likely action items, decisions, mentions, and deadline or urgency highlights.

## Run it

Open `index.html` in a modern browser. There is no build step, account, API key, or server.

## Privacy and analysis

Conversation text is processed by JavaScript in the current browser page. The app does not upload conversations or call an AI service. Its lightweight analyzer uses message patterns and priority signals, so its summaries are heuristic rather than generated by a remote language model. Imported conversations live in memory for the current page session and are not persisted.

The app uses system fonts and makes no network requests. It works offline once the local files are available.
